Shadch-UI组件库和管理后台UI

发表于 2026-03-09 分类于 前端

shadcn-ui

https://github.com/shadcn-ui/ui 是一套可以自定义、扩展和构建的精美组件。使用它来构建你自己的组件库。完全基于 Tailwind CSS 实现，其核心设计哲学就是将 Tailwind CSS 的原子化特性发挥到极致。

  • 预览地址：https://ui.shadcn.com/examples

  • Vite 摸板： https://www.shadcn.io/template/category/vite

  • Skills: https://ui.shadcn.com/docs/skills
    Skills使像 Claude Code 这样的 AI 助手能够获得关于 shadcn/ui 的项目感知上下文。安装后，你的 AI 助手知道如何使用正确的 API 和模式来查找、安装、组合和自定义组件。

shadcn-admin

https://github.com/satnaing/shadcn-admin

基于 Shadcn 使用 React + Vite 构建的管理后台 UI。

注意：但这不是一个启动项目（模板）

  • 预览地址：shadcn-admin.netlify.app/

shadcn-vue-admin

https://github.com/Whbbit1999/shadcn-vue-admin

基于 【satnaing/shadcn-admin】采用 shadcn-vue + Vue3 + Vite 打造的一个管理后台 UI。

  • 预览地址：shadcn-vue-admin.netlify.app/
