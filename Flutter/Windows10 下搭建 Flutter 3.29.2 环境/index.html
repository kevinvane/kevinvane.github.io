3.1 修改maven仓库

默认情况下，网络是不同的，因为仓库 “https://maven.google.com/“ 有网络问题。
修改 D:\public_share\flutter\packages\flutter_tools\lib\src\http_host_validator.dart 文件解决：

  • $ vim flutter/packages/flutter_tools/lib/src/http_host_validator.dart
  • 把 ‘https://maven.google.com/‘ 改为 ‘https://dl.google.com/dl/android/maven2/‘
  • 删除  flutter/bin/cache 目录
  • 重新运行 '$ flutter doctor'

3.2 修改依赖仓库

默认依赖源，网络是访问不同的，这个问题要通过设置镜像站点解决 https://docs.flutter.dev/community/china#configuring-flutter-to-use-a-mirror-site

四、安装Android Studio 插件

  • 打开 Android Studio。
  • 打开插件设置。
  • 然后选择 Flutter 插件并点击 安装。
  • 当弹出安装 Dart 插件提示时，点击 Yes。
  • 当弹出重新启动提示时，点击 Restart。

六、Jetpack Compose 和 Flutter 开发语法相似度很高？

以下是 Deepseek 回答：

Jetpack Compose（Android 的现代 UI 框架）和 Flutter（Google 的跨平台 UI 框架）在语法和设计理念上确实有许多相似之处，但也有一些关键差异。以下是它们的相似点和不同点分析：

6.1 相似点

  1. 声明式 UI
    两者都采用声明式编程范式，开发者通过描述 UI 的最终状态（而非一步步命令式更新）来构建界面。例如：

    • Flutter:
    • Compose:

  2. 基于函数的组件
    UI 都是由可组合的函数（Flutter 叫 Widget，Compose 叫 Composable）构建的，通过嵌套函数调用实现布局。

  3. 状态管理
    都强调状态驱动 UI 更新：

    • Flutter 使用 StatefulWidget 或状态管理库（如 Provider、Riverpod）。
    • Compose 使用 remember 和 mutableStateOf 等机制。

  4. 热重载（Hot Reload）
    两者都支持快速刷新界面，提升开发效率。

  5. Material Design 支持
    均内置对 Material Design 组件的原生支持（如 Button、Card 等）。

6.2 不同点

  1. 语言基础

    • Flutter：使用 Dart 语言（语法接近 Java/JavaScript，但有独特的特性如 .. 级联操作符）。
    • Compose：使用 Kotlin 语言（支持协程、扩展函数等特性，与 Android 生态深度集成）。

  2. 组件命名与风格

    • Flutter 的组件通常以 Widget 结尾（如 TextWidget、ContainerWidget），而 Compose 直接使用语义化名称（如 Text、Box）。
    • 布局方式略有差异：
      • Flutter 常用 Row/Column/Stack。
      • Compose 用 Row/Column/Box。

  3. 状态管理实现

    • Flutter 需要显式区分 StatelessWidget 和 StatefulWidget。
    • Compose 通过 remember 和状态托管（如 ViewModel）更灵活地管理状态。

  4. 平台依赖性

    • Flutter：跨平台（iOS、Android、Web、桌面等），UI 通过 Skia 引擎自绘，不依赖原生控件。
    • Compose：目前主要用于 Android（Compose Multiplatform 正在扩展支持其他平台，但成熟度不如 Flutter）。

  5. 布局系统

    • Flutter 的布局逻辑更显式（如 padding: EdgeInsets.all(8)）。
    • Compose 通过 Modifier 链式调用（如 Modifier.padding(8.dp)）。

为什么感觉语法相似？

  • Google 团队在设计两者时共享了类似的现代化 UI 开发理念（声明式、响应式）。
  • 都借鉴了 React 等前端框架的思想（如“状态驱动视图”）。
  • Dart 和 Kotlin 同属现代语言，语法简洁性上有共同点（如 lambda 表达式、类型推断）。

如何选择？

  • 选 Flutter：需要跨平台、希望一套代码覆盖多端。
  • 选 Compose：专注 Android 开发、需深度集成原生能力或已有 Kotlin 代码库。
